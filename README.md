5. TYPOGRAPHY — MAKE IT LARGE, PREMIUM, AND EDITORIAL

Typography is one of the most important parts of this project.

I specifically want large, premium, expressive typography.

The website must not look small, cramped, or overly cautious.

Typography direction

Use a sophisticated editorial serif for major headlines and a modern sans-serif for supporting text.

Possible type pairing:

Display: Cormorant Garamond, DM Serif Display, Playfair Display, or a similarly refined editorial serif.

Body and interface: Manrope, DM Sans, Inter, or a similarly clean contemporary sans-serif.

Choose the final pairing based on visual harmony, readability, performance, and licensing.

Do not use too many fonts.

Typography hierarchy

Create a proper responsive type scale.

The main homepage hero should feature a genuinely large headline, approximately:

Desktop: 80–120px where the composition and viewport allow.

Tablet: approximately 60–84px.

Mobile: approximately 42–64px.

These are design targets, not rigid values. Adjust based on the actual text, screen width, and layout.

The headline should feel like a premium editorial statement.

Use CSS clamp() and responsive typography rather than fixed values that break on smaller screens.

Typography details

Large, expressive hero headline.

Elegant serif section headings.

Strong contrast between display and body type.

Generous line-height.

Carefully controlled letter spacing.

Refined uppercase eyebrow labels.

Delicate italic accents only where appropriate.

Clear body text.

No tiny unreadable paragraphs.

No excessive uppercase text.

No unnecessary bolding.

No overly decorative fonts.

Typography should create a sense of luxury through proportion, spacing, and restraint.

Do not make the entire website serif.

Do not make every heading the same size.

Use typography to establish rhythm and guide the visitor through the page.
